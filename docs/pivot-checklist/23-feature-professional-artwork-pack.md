# 23. Feature — Professional Artwork Pack

> Source: PDF pages 17–18, 21–22 — priority feature #6 ("One-Click Professional Pack"), detailed on "6. Professional Artwork Pack", plus "Dashboard placement"
> Priority: **6 of 10** · Build tier: **NOW** · Build order position: **4th** (built right after Buyer Intent Card, before Private Viewing Room)
> Depends on: [18-feature-artwork-readiness-scan.md](18-feature-artwork-readiness-scan.md)

## What it is

- **What the artist sees:** a downloadable artwork sheet with image, biography, details, rights and QR.
- **What the buyer sees:** consistent information suitable for internal review.
- **Why it impresses:** useful for galleries, exhibitions, buyers and press.

## Build

- [ ] One button: **"Generate Professional Pack"**

## Must include

- [ ] Artist name and Artbank ID
- [ ] Artwork image
- [ ] Title, year, medium and dimensions
- [ ] Artwork statement
- [ ] Availability
- [ ] Rights information
- [ ] Passport status
- [ ] COA status
- [ ] Contact link
- [ ] QR code

## Output

- [ ] Mobile share page
- [ ] Downloadable PDF
