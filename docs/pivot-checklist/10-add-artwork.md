- [ ] **DELETE** — Automatic AI-generated facts → the artist must confirm every fact themselves, nothing auto-populated and trusted blindly
- [ ] **DELETE** — Any implication that uploading transfers ownership → explicitly state that ownership remains with the artist

## Add Artwork — required steps, in order

1. [ ] Upload artwork images
2. [ ] Title, year, medium and dimensions
3. [ ] Artwork description and story
4. [ ] Creator and ownership statement
5. [ ] Availability and possible earning routes
6. [ ] Rights and permitted uses
7. [ ] Evidence and supporting files
8. [ ] Visibility: **Public, Private or Unlisted**
9. [ ] Review and publish

## Notes

- "Ownership remains with the artist" is a legal/trust statement — get the exact wording checked rather than improvising it.
