## What it is

- **What the artist sees:** one next action for every artwork.
- **What the buyer sees:** better-prepared artwork and faster responses (indirect benefit).
- **Why it impresses:** each artwork actively "works" instead of sitting passively in a portfolio.

## Rule

> Every artwork should have **one** recommended action — not a list, not a backlog. One.

## Situation → recommended action mapping

Build this exact decision table:

| Situation | Recommended Action |
|---|---|
| Missing evidence | Add ownership statement |
| No professional description | Improve artwork story |
| High anonymous interest | Share through Smart Artwork Link |
| Identified buyer | Respond to enquiry |
| Licensing interest | Confirm available rights |
| Suitable exhibition | Prepare application |
| Incomplete Passport | Add missing documentation |
| No activity | Improve presentation or availability |
