# 21. Feature — Private Viewing Room

> Source: PDF pages 17, 20 — priority feature #4, detailed on "4. Private Viewing Room"
> Priority: **4 of 10** · Build tier: **NOW** · Build order position: **5th** (built after Professional Artwork Pack — see [00-overview-and-timeline.md](00-overview-and-timeline.md))
> Depends on: [09-my-works.md](09-my-works.md), [20-feature-buyer-intent-card.md](20-feature-buyer-intent-card.md)

## What it is

- **What the artist sees:** select works, control what information is shared, and set an access expiry.
- **What the buyer sees:** a private, curated presentation instead of public browsing.
- **Why it impresses:** makes ordinary artists look institutionally represented.

## How it works

> The artist selects artworks and creates **one controlled link.**

## Must include

- [ ] Viewing-room title
- [ ] Selected artworks
- [ ] Private notes
- [ ] Availability
- [ ] Price visibility control (show/hide price per room)
- [ ] Download permission (allow/deny)
- [ ] Buyer identity requirement (gate access behind identity disclosure)
- [ ] Expiry date
- [ ] **Contact Artist** action
- [ ] **Request Discussion** action
- [ ] Activity summary for the artist (who viewed what, when)

## ⚠️ Scope boundary

> **Do not build video calls, payments or complex contracts yet.**

Keep this feature to link/content curation + access control only.

## Notes

- Dashboard placement: lives under the **account menu** (see [07-artspace-shell-and-navigation.md](07-artspace-shell-and-navigation.md) placement table) and the buyer workspace shows **Saved Works and Viewing Rooms**.
