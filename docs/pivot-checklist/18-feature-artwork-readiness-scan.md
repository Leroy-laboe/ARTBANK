## What it is

- **What the artist sees:** the exact missing items preventing the artwork from being trusted, presented or monetized.
- **What the buyer sees:** a complete, professional artwork record (the *result* of the artist completing the scan).
- **Why it impresses:** Artbank tells the artist exactly what to fix, instead of a vague quality score.

## Changes

- [ ] **CHANGE** — "Passport 60% complete" (a bare percentage) → **"4 items required before this work is buyer-ready"** (concrete count of concrete items)
- [ ] **CHANGE** — Generic score → explicit missing-item list, e.g. *"Missing: dimensions, ownership statement, availability and rights"*
- [ ] **ADD** — No benefit currently explained → state the payoff: *"Complete these to unlock the Professional Pack and Private Viewing Room"*

## The four readiness states

Build exactly these four states — no numeric/percentage score:

| State | Meaning |
|---|---|
| Documented | Essential artwork information completed |
| Presentable | Images, description and professional materials ready |
| Trust-Ready | Ownership and supporting evidence supplied |
| Commercially Ready | Availability, rights and enquiry options confirmed |

- [ ] Documented
- [ ] Presentable
- [ ] Trust-Ready
- [ ] Commercially Ready

## ⚠️ Hard rule

> **Do not call this an artistic-quality score.**

This is a completeness/readiness measure, not a judgment of the art itself — keep the language, iconography and framing entirely about documentation completeness. This is the direct replacement for the deleted MRI score (see [17-do-not-build-guardrails.md](17-do-not-build-guardrails.md)) — it must not accidentally recreate it.
