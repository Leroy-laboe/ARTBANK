# 19. Feature — Smart Artwork Link + QR

> Source: PDF pages 17, 19 — priority feature #2, detailed on "2. Smart Artwork Link"
> Priority: **2 of 10** · Build tier: **NOW** · Build order position: **2nd**
> Depends on: [11-artwork-record-passport.md](11-artwork-record-passport.md)

## What it is

- **What the artist sees:** one shareable link with viewer-source statistics.
- **What the buyer sees:** a clean artwork page with **Contact, Request Availability and Present Yourself** actions.
- **Why it impresses:** artists can replace scattered Instagram DMs with one professional link.

## Every artwork must receive

- [ ] Permanent Artbank URL
- [ ] Shareable QR code
- [ ] Social-media preview card (OG/Twitter-card style image + metadata)
- [ ] **Contact Artist** button
- [ ] **Request Availability** button
- [ ] **Request Private Viewing** button
- [ ] **Present Yourself to Artist** button
- [ ] Source tracking: **Instagram, Threads, RedNote, QR, or direct**
- [ ] Identity disclosure required before serious access (i.e. before contact/availability/viewing actions unlock)

## Dashboard display example

The artist-facing summary should read like this (real example from the brief):

> "Silent Harmony received 27 visits from Instagram. Two viewers presented themselves. One requested availability."

> This is called out explicitly as **"one of Artbank's strongest immediate hooks"** — worth extra polish relative to its priority ranking.
