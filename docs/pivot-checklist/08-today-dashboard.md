## Changes

- [ ] **IMPROVE** — Welcome message only → personalized greeting with a real status line, e.g. *"Good morning, Maya. Three artworks are working for you today."*
- [ ] **DELETE** — Many statistics at the top → show **one** important next action first, not a stats wall
- [ ] **CHANGE** — "Total views" → **"12 new views — 3 identified viewers"** (split anonymous traffic from identified people)
- [ ] **DELETE** — Public ranking → **Private Professional Readiness** (private to the artist only)
- [ ] **CHANGE** — Generic recommendations → **one** explainable **HGI Next Action**
- [ ] **DELETE** — Empty charts → use short, actionable cards instead
- [ ] **CHANGE** — "Estimated earnings" → show **recorded** earnings only (no projections/estimates)

## Today screen — module order

Build these six modules top to bottom:

1. [ ] **Needs Your Decision** — maximum three urgent actions
2. [ ] **Real Interest** — identified viewers and enquiries
3. [ ] **Artworks at Work** — artwork movement and status
4. [ ] **Best Opportunity** — strongest current match
5. [ ] **Money and Rights** — completed/pending earnings and licences
6. [ ] **Professional Readiness** — missing information and next improvement
